Vectors — The Building Blocks of Data

Unit 1 · Mathematics for AI/ML · Lesson 1

Why vectors matter

Every piece of data that enters an AI model is turned into numbers arranged in a special way. That arrangement is called a vector.

  • An image of a cat → a long list of numbers (pixel values)
  • A sentence → a list of numbers that capture its meaning
  • A student’s marks in 5 subjects → a vector of 5 numbers
  • A house (area, bedrooms, age, location) → a vector of features

If you understand vectors deeply, you understand the language that machines speak.

What is a vector? (Simple definition)

A vector is an ordered list of numbers. We write it like this:

Row form v = [3, 4]
Column form v = [ 3 ]
    [ 4 ]

The numbers inside are called components. The number of components is the dimension.

  • [3, 4] is a 2-dimensional vector (lives on a plane)
  • [1, 0, −2] is a 3-dimensional vector
  • In real AI we routinely use vectors with hundreds or thousands of dimensions

Two ways to look at the same vector

1. Algebraic view — just a list of numbers (useful for calculation).

2. Geometric view — an arrow starting from the origin (useful for intuition).

The vector [3, 4] is an arrow that goes 3 units right and 4 units up. Its length (also called magnitude or norm) is the straight-line distance from the origin to the tip.

Using Pythagoras:

‖v‖ = √(3² + 4²) = √(9 + 16) = √25 = 5
General formula for magnitude ‖v‖ = √(v₁² + v₂² + … + vₙ²)
Worked Example 1 — Magnitude

Problem: Find the magnitude of a = [6, 8].

  1. Write the formula: ‖a‖ = √(6² + 8²)
  2. Squares: 6² = 36, 8² = 64
  3. Add: 36 + 64 = 100
  4. Square root: √100 = 10
Answer: The magnitude is 10.

Vector addition

To add two vectors of the same dimension, add the corresponding components:

u + v = [u₁ + v₁, u₂ + v₂, …, uₙ + vₙ]

Geometrically: place the tail of the second vector at the tip of the first. The resulting arrow is the sum.

Worked Example 2 — Addition

Problem: u = [2, 5], v = [−1, 3]. Find u + v.

  1. First components: 2 + (−1) = 1
  2. Second components: 5 + 3 = 8
Answer: u + v = [1, 8]

Scalar multiplication

A scalar is just an ordinary number. Multiplying a vector by a scalar multiplies every component:

c · v = [c·v₁, c·v₂, …, c·vₙ]
  • c > 1 → vector gets longer (stretched)
  • 0 < c < 1 → vector gets shorter
  • c < 0 → vector points in the opposite direction

This is exactly what happens when a neural network multiplies inputs by weights.

Worked Example 3 — Scalar Multiplication

Problem: v = [4, −2]. Compute 3v and −0.5v.

  1. 3v = [3×4, 3×(−2)] = [12, −6]
  2. −0.5v = [−0.5×4, −0.5×(−2)] = [−2, 1]
Answer: 3v = [12, −6], −0.5v = [−2, 1]

The Dot Product — the most important operation

The dot product of two vectors is a single number:

u · v = u₁v₁ + u₂v₂ + … + uₙvₙ

It also has a geometric meaning:

u · v = ‖u‖ × ‖v‖ × cos θ

where θ is the angle between the two vectors.

  • θ = 0° (same direction) → cos θ = 1 → largest positive value
  • θ = 90° (perpendicular) → cos θ = 0 → dot product is zero
  • θ = 180° (opposite) → cos θ = −1 → largest negative value

This single idea powers recommendation systems, attention in Transformers, and similarity search.

3Blue1Brown — Dot products and duality (Essence of Linear Algebra). Visual intuition for why the formula works.

Worked Example 4 — Dot Product

Problem: a = [1, 2, 3], b = [4, −5, 6]. Compute a · b.

  1. 1×4 = 4
  2. 2×(−5) = −10
  3. 3×6 = 18
  4. Add: 4 + (−10) + 18 = 12
Answer: a · b = 12

Cosine Similarity — measuring how alike two things are

From the geometric form we can isolate the cosine:

cos θ = (u · v) / (‖u‖ × ‖v‖)

This value always lies between −1 and +1. Values close to +1 mean the vectors point in almost the same direction (very similar).

Worked Example 5 — Cosine Similarity (tiny dataset)

Problem: Two students answered a 3-question quiz.
Student A = [8, 6, 9]
Student B = [7, 5, 10]
How similar are their answer patterns?

  1. Dot product: 8×7 + 6×5 + 9×10 = 56 + 30 + 90 = 176
  2. ‖A‖ = √(8² + 6² + 9²) = √(64+36+81) = √181 ≈ 13.45
  3. ‖B‖ = √(7² + 5² + 10²) = √(49+25+100) = √174 ≈ 13.19
  4. Cosine = 176 / (13.45 × 13.19) ≈ 176 / 177.4 ≈ 0.992
Answer: Cosine similarity ≈ 0.992 (extremely similar)
Real AI systems Image search, ChatGPT attention, Netflix recommendations, and spam filters all rely on vectors and cosine similarity (or the raw dot product).

Quick check: What is the cosine similarity between u = [3, 0] and v = [0, 4]?

Key takeaways — Vectors

  • A vector is an ordered list of numbers (and also an arrow from the origin).
  • Magnitude ‖v‖ = √(Σ vᵢ²) measures length.
  • Addition and scalar multiplication are component-wise.
  • Dot product u·v = Σ uᵢvᵢ = ‖u‖‖v‖ cos θ is the key operation.
  • Cosine similarity = normalized dot product → measures directional similarity.

Matrices — Organizing Data & Transformations

Unit 1 · Mathematics for AI/ML · Lesson 2

What is a matrix?

A matrix is a rectangular table of numbers arranged in rows and columns. We say it is an m × n matrix if it has m rows and n columns.

A = | 1 2 3 |
    | 4 5 6 |

This is a 2 × 3 matrix (2 rows, 3 columns).

In machine learning:

  • A whole dataset is often stored as a matrix (each row = one example)
  • The weights of a neural-network layer are a matrix
  • Images can be flattened into matrices of pixel values

Matrix-vector multiplication

When you multiply a matrix by a vector, you get a new vector. Each component of the result is the dot product of one matrix row with the vector.

A · x = result vector
Worked Example — Matrix × Vector

Problem:
A = | 1 2 |    x = | 3 |
    | 0 1 |         | 4 |

  1. First row · x = 1×3 + 2×4 = 3 + 8 = 11
  2. Second row · x = 0×3 + 1×4 = 0 + 4 = 4
Answer: A · x = [11, 4]

Matrix-matrix multiplication

To multiply two matrices A (m × n) and B (n × p) the result is an m × p matrix. Each entry is the dot product of a row of A with a column of B.

Important rule The number of columns of the first matrix must equal the number of rows of the second matrix.
Worked Example — Matrix × Matrix (tiny numbers)

Problem:
A = | 1 2 |    B = | 5 6 |
    | 3 4 |         | 7 8 |

  1. Top-left: 1×5 + 2×7 = 5 + 14 = 19
  2. Top-right: 1×6 + 2×8 = 6 + 16 = 22
  3. Bottom-left: 3×5 + 4×7 = 15 + 28 = 43
  4. Bottom-right: 3×6 + 4×8 = 18 + 32 = 50
Answer: A · B = | 19 22 |
                   | 43 50 |
Why this matters in neural networks One layer of a neural network is basically: output = activation( WeightMatrix · input + bias ). Understanding matrix multiplication is understanding how information flows through the network.

If A is 3×2 and B is 2×4, what is the shape of A · B?

Key takeaways — Matrices

  • A matrix is a table of numbers (m rows × n columns).
  • Matrix × vector produces a new vector (each entry = row · vector).
  • Matrix × matrix is defined only when the inner dimensions match.
  • Neural-network layers are matrix multiplications + a non-linear activation.

Calculus & Gradients — How Models Learn

Unit 1 · Mathematics for AI/ML · Lesson 3

Derivative — rate of change

The derivative of a function f(x) at a point tells you how steep the curve is at that point (slope of the tangent line).

f'(x) = limh→0 [f(x+h) − f(x)] / h

For simple power functions we use the power rule:

If f(x) = xⁿ   then   f'(x) = n · xⁿ⁻¹
Worked Example — Derivative

Problem: f(x) = 3x² + 2x − 5. Find f'(x).

  1. Derivative of 3x² = 3 · 2x = 6x
  2. Derivative of 2x = 2
  3. Derivative of −5 = 0
Answer: f'(x) = 6x + 2

Gradient — derivative for many variables

When a function depends on several variables (for example loss depends on many weights), the gradient is the vector of all partial derivatives.

∇f = [ ∂f/∂x₁ , ∂f/∂x₂ , … , ∂f/∂xₙ ]

The gradient points in the direction of steepest increase. Therefore −∇f points in the direction of steepest decrease — exactly the direction we want when we minimize a loss function.

Worked Example — Gradient of a simple function

Problem: f(x, y) = x² + 3y² − 2xy. Compute the gradient at the point (1, 2).

  1. ∂f/∂x = 2x − 2y   → at (1,2): 2(1) − 2(2) = 2 − 4 = −2
  2. ∂f/∂y = 6y − 2x   → at (1,2): 6(2) − 2(1) = 12 − 2 = 10
Answer: ∇f(1,2) = [−2, 10]
Intuition Think of the loss as the height of a hilly landscape. The gradient tells you which way is uphill. To reduce the loss we walk downhill — i.e. we subtract a small multiple of the gradient from the current parameters.

Key takeaways — Gradients

  • Derivative = slope = rate of change of a function of one variable.
  • Gradient = vector of partial derivatives for multi-variable functions.
  • Gradient points uphill; we move opposite to the gradient to minimize loss.

Optimization Basics — Finding the Best Model

Unit 1 · Mathematics for AI/ML · Lesson 4

Loss function

A loss function measures how wrong the model’s predictions are. The goal of training is to find the parameters (weights) that make the loss as small as possible.

Simple example — Mean Squared Error for one prediction:

L = (y_true − y_pred)²

Gradient Descent — the core algorithm

1. Start with random weights.
2. Compute the gradient of the loss with respect to the weights.
3. Update:   w ← w − η · ∇L
4. Repeat until the loss stops decreasing.

η (eta) is the learning rate — how big a step we take.

Worked Example — One step of gradient descent (tiny data)

Setup: We want to fit a line y = w·x to the single point (x=2, y=8). Start with w = 1. Learning rate η = 0.1. Loss = (y − w·x)².

  1. Current prediction: ŵ = 1 · 2 = 2
  2. Loss: (8 − 2)² = 36
  3. Gradient ∂L/∂w = −2 · (8 − w·2) · 2 = −4 · (8 − 2) = −24
  4. Update: w ← 1 − 0.1 · (−24) = 1 + 2.4 = 3.4
  5. New prediction: 3.4 · 2 = 6.8 (much closer to 8)
  6. New loss: (8 − 6.8)² = 1.44 (much smaller)
After one step the weight moved from 1 → 3.4 and the loss dropped from 36 → 1.44.
Learning-rate tip Too large η → the algorithm jumps around and may never settle.
Too small η → learning is very slow.
Typical starting values: 0.01, 0.001, 0.0001. We often try a few and pick the best.

In the update rule w ← w − η · ∇L, why do we subtract the gradient?

Key takeaways — Optimization

  • Loss measures how wrong the model is.
  • Gradient descent repeatedly moves parameters opposite to the gradient.
  • Learning rate controls step size; it must be chosen carefully.
  • Almost every modern neural network is trained with some form of gradient descent.

Probability & Statistics Essentials

Unit 2 · Probability theory, Bayes, descriptive statistics

Basic probability

Probability of an event is a number between 0 and 1 that tells us how likely the event is.

P(A) = number of favorable outcomes / total possible outcomes
Worked Example — Simple probability

A bag contains 3 red and 7 blue balls. Probability of drawing a red ball?

P(red) = 3 / 10 = 0.3

Conditional probability & Bayes’ theorem

P(A|B) means “probability of A given that B has already happened”.

P(A|B) = P(B|A) · P(A) / P(B)

This is Bayes’ theorem. It lets us update our belief about A after seeing evidence B.

Worked Example — Bayes (medical test)

Disease affects 1% of people. Test is 99% accurate (true positive rate 0.99, false positive rate 0.01). You tested positive. What is the probability you really have the disease?

  1. P(D) = 0.01, P(not D) = 0.99
  2. P(+|D) = 0.99, P(+|not D) = 0.01
  3. P(+) = 0.99×0.01 + 0.01×0.99 = 0.0198
  4. P(D|+) = (0.99 × 0.01) / 0.0198 ≈ 0.5
Even with a 99% accurate test, a positive result only gives about 50% probability of having the disease (because the disease is rare).

Mean, variance, standard deviation

For a small dataset x = [2, 4, 4, 6, 8]:

  • Mean μ = (2+4+4+6+8)/5 = 24/5 = 4.8
  • Variance = average of squared differences from the mean
  • Standard deviation = √variance (same units as the data)
Worked Example — Mean & Variance

Data: [2, 4, 4, 6, 8], mean = 4.8

  1. Squared diffs: (2−4.8)²=7.84, (4−4.8)²=0.64, (4−4.8)²=0.64, (6−4.8)²=1.44, (8−4.8)²=10.24
  2. Sum = 20.8
  3. Variance (population) = 20.8 / 5 = 4.16
  4. Std dev = √4.16 ≈ 2.04
Mean = 4.8, Variance = 4.16, Std Dev ≈ 2.04

Key takeaways — Probability

  • Probability quantifies uncertainty (0 to 1).
  • Bayes’ theorem updates beliefs when new evidence arrives.
  • Mean, variance and standard deviation summarize a dataset.
  • These ideas appear in Naive Bayes classifiers, evaluation metrics, and uncertainty estimation.

NumPy — fast numerical arrays

import numpy as np

# Create a vector
v = np.array([3, 4])
print(v)          # [3 4]
print(np.linalg.norm(v))  # magnitude = 5.0

# Dot product
a = np.array([1, 2, 3])
b = np.array([4, -5, 6])
print(np.dot(a, b))       # 12

# Matrix multiplication
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])
print(A @ B)              # [[19 22] [43 50]]

Pandas — tables of data

import pandas as pd

df = pd.DataFrame({
    "height": [160, 170, 165, 180],
    "weight": [55, 70, 60, 80]
})
print(df.head())
print(df["height"].mean())   # average height

Matplotlib — simple plots

import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
y = [2, 4, 6, 8]
plt.plot(x, y, marker="o")
plt.xlabel("x")
plt.ylabel("y")
plt.title("Simple line")
plt.show()

Scikit-learn — first model in 6 lines

from sklearn.linear_model import LinearRegression
import numpy as np

X = np.array([[1], [2], [3], [4]])
y = np.array([2, 4, 6, 8])

model = LinearRegression()
model.fit(X, y)
print(model.predict([[5]]))   # ≈ [10]
